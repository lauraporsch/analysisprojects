<h1><strong>About this project</strong></h1>
<p>This project analyzes historical mortality records from the Vienna General Hospital to illustrate&nbsp;how early data analysis revealed the link between hand hygiene and maternal survival.</p>
<p>By retracing Dr. Ignaz Semmelweis&rsquo;s documentation with modern Python tools, the project demonstrates how statistical evidence uncovered the true cause of childbed fever and supported a life-saving procedural change.</p>
<p>This project uses two historical datasets. The first contains yearly birth and death counts for Clinic 1 and Clinic 2 from 1841 to 1846. Both clinics followed the same procedures except for one key difference: only Clinic 2 practiced handwashing. The second dataset combines births and deaths from both clinics, recorded monthly from 1841 to 1849, giving a more detailed view of trends before and after handwashing was introduced.</p>
<h2><strong>The Core Question Behind This Project</strong></h2>
<p>Did handwashing meaningfully reduce maternal deaths in the Vienna General Hospital, and can the original findings be confirmed using modern data analysis techniques?</p>
<h2>Main Takeaway</h2>
<p>After handwashing and instrument cleaning became mandatory, maternal deaths fell by 8.37%. The small&nbsp;p-value (0.0000002985) shows that this drop is almost certainly not due to chance, the evidence strongly supports that handwashing made a real, significant difference.&nbsp;</p>
<h2><strong>Tools Used</strong></h2>
<p>Python, Jupyter Notebooks</p>
